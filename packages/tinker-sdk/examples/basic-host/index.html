Tinker Ask — example host

server.mjs holds TINKER_SERVICE_TOKEN and proxies /api/tinker/transcribe + /api/tinker/ask. The browser never sees the token. Production pages should mount TinkerAsk.create({ proxyUrl: "/api/tinker", … }) from @tinker/sdk/browser (see the package README).

This page is a tiny typed-only stand-in of that contract so the example runs without a bundler.
