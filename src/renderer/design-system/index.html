tinker

Design system

The marks, colors, and type that make tinker feel like tinker. Tokens live in src/renderer/design-tokens.css; the globe geometry lives in src/renderer/tokens/rainbow-web.json.

Marks

Tinker mark

The multi-colored globe — tinker's primary identity. Built from tokens/rainbow-web.json, so a single edit to the dictionary updates every surface.

Calico cat & globe

A friendlier brand illustration: a calico cat batting the tinker globe like a ball of yarn. For welcome surfaces, empty states, and any moment where the app wants to feel warm.

Logo palette

The seven colors of the rainbow globe. No violet, no indigo — same as the upstream token dictionary.

Pastel rainbow

The full expressive palette for UI accents. Each color also exposes a paired -light tint in design-tokens.css.

Brand neutrals

The grounded tones used across chrome, cards, and prose.
