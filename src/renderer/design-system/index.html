tinker

Design system

The marks, colors, type, spacing, shadows, and components that make tinker feel like tinker. Tokens live in src/renderer/design-tokens.css; the globe geometry lives in src/renderer/tokens/rainbow-web.json. Display face is Fraunces (SOFT 100, WONK 0); reading face is Instrument Sans.

Marks

Tinker mark

The multi-colored globe — tinker's primary identity. Built from tokens/rainbow-web.json, so a single edit to the dictionary updates every surface.

Calico cat & globe

A friendlier brand illustration: a calico cat batting the tinker globe like a ball of yarn. For welcome surfaces, empty states, and any moment where the app wants to feel warm.

Logo palette

The seven colors of the rainbow globe. No violet, no indigo — same as the upstream token dictionary.

Pastel rainbow

Brand neutrals

Spacing

One scale, eight steps. Bars are drawn to actual pixel width — no relative scaling on this page.

Shadows

House rule: shadows on buttons only. Cards, panels, modals, inputs, and surfaces all stay flat — they use a 1px hairline border (--color-border) for separation. Focus is a halo, not a shadow.

Motion

There are no motion tokens. State changes are instant by design — no transitions, no springs, no eases. If you reach for one, reconsider.

A quiet place to be on the web.
Nothing here performs. Buttons commit on click. Modals appear. Focus snaps in. The interface is a room, not a stage.

What this system never does

House rules — the never-do list.

  • ShadowsNo shadows except on buttons. Cards, panels, modals, inputs — all flat. Hairline border does the work.
  • MotionNo motion. Instant state changes. No transitions, no springs, no eases on hover, press, modal entry, or focus.
  • VoiceNo emoji, no exclamation points, no marketing voice, no AI tells.
  • TypeDisplay is dialed warm (Fraunces, SOFT 100, WONK 0). No quirky spurs, no slab terminals — if it reads brash, it is wrong.
