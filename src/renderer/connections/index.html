Connections

A small plugin marketplace: connect Notion or GitHub with OAuth so Claude can read context while you write. Your tokens stay on the server, encrypted. Writes stay gated by Allow writes.

This is separate from MCP access, which lets bots call Tinker.

    Context pages

    Pick Notion pages as business context and technical goals. Read-only tools fetch them for essay questions, classification, and coding exercises.

    Allow write tools?

    Write tools can create and change content in this workspace. Read tools stay available either way.
