Connections

A small plugin marketplace: connect Notion or GitHub with OAuth so Claude can read context while you write. Your tokens stay on the server, encrypted. Writes stay gated by Allow writes.

This is separate from MCP access, which lets bots call Tinker.

Notion essays

Connect Notion so a finished essay lands in an Essays database (title, body, date, learning goal). Pick a parent page; Tinker creates the database under it when needed.

    Context pages

    Search Notion (read-only) and pick pages as business context or technical goals. They feed essay questions, classification, and coding exercises.
