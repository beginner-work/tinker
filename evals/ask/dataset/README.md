# Ask eval dataset (private)

The question bank, cases, and essay snapshot live in the private pack:

```
$TINKER_PRIVATE_DIR/evals/ask/dataset/
$TINKER_PRIVATE_DIR/evals/ask/cases/
$TINKER_PRIVATE_DIR/evals/ask/fixtures/essays.json
$TINKER_PRIVATE_DIR/evals/ask/rubric.md
$TINKER_PRIVATE_DIR/evals/ask/rubric-agreement.md
$TINKER_PRIVATE_DIR/evals/ask/THRESHOLDS.md
```

Set `TINKER_PRIVATE_DIR` or `TINKER_EVAL_ASK_DIR` before `npm run eval:ask`.
