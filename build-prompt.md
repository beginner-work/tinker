# tinker — build prompts (regeneration manifest)

> Version: v1.0
> Maintained by the build-prompts audit (2026-05).

This file is the index for tinker's build prompts. The goal of this folder is
concrete: **the prompts in `build-prompts/` collectively describe every surface
of the tinker app, so the app could be regenerated from them alone — in one
shot, in build order.** Each prompt is the imperative spec behind one surface,
grounded against the shipped code (every file path, symbol, storage key,
endpoint, model id, and price in a prompt resolves in this repo).

The companion repo `beginner` uses the **same** structure (root `build-prompt.md`
manifest + a `build-prompts/` folder of per-surface specs).

## How to use

Build top to bottom. The foundation (design system, shell, auth, data) comes
first; the writing core next; the pitch surfaces after that; the paid/edge
surfaces last. Within each prompt, follow its own `Build sequence` and stop at
every `CHECKPOINT`.

## Conventions

- **Headers.** Every prompt opens with a title, a `> Version:` line, and a
  provenance line: `> Generated by the founder-package skill (product spec
  flow).` for interview-derived prompts, and/or `> Reconstructed from shipped
  code by the build-prompts audit (2026-05).` for audit-derived ones. Prompts
  rebased onto current code also carry a `> Rebased against shipped code…` line.
- **Grounding.** Paths/symbols/keys/endpoints/models in a prompt must resolve in
  this repo. The model ids in this codebase are `claude-opus-4-7`
  (`writing.js`, `api/claude/converse.js`) and `claude-haiku-4-5-20251001`
  (`api/search.js`, `api/classify/index.js`, `api/feed/adjacent.js`,
  `api/_lib/pitches-clusterer.js`). There is no `claude-sonnet-4-6`.
- **Deck headings.** The eleven `DECK_HEADINGS` (verbatim, in order): The Problem,
  A Persona, Why Now?, The Team, The Product, How We Make Money, Go to Market,
  The Moat, The Vision, Competition, The Ask.
- **Retired.** `linkedin-review-page.md` was retired in this audit — its
  `linkedin-fit.js` surface was removed and superseded by the social feed.
