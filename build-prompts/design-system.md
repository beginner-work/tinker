# Build the tinker design system

> Version: v0.100
> Generated by the founder-package skill (product spec flow).
> Reconstructed from shipped code by the build-prompts audit (2026-05).

This spec is the visual canon every other tinker prompt leans on. It owns the
tokens (the `--logo-*` rainbow palette, the type scale, spacing, radii, the
Fraunces + Instrument Sans pairing), the component styling (the warm-paper
background, the rainbow gradient usage), the brand-mark data dictionary, and the
bundled design-system reference page. The house rules stated here — no motion in
the product layer, shadows on buttons only, no pure white and no harsh black,
the rainbow-web mark — are the rules the pitch, script, validation, sidebar, and
feed surfaces all cite rather than restate. Calm, warm, and quiet: the spirit is
*"a quiet place to be on the web,"* and nothing here performs.

## Anti-patterns — do not repeat

- **Don't ship motion in the product layer.** The token file is explicit: *"No
  `--motion-*` tokens exist. If you reach for a transition or an animation
  timing, reconsider."* The design-system bundle's never-do list says *"No
  motion. Instant state changes. No transitions, no springs, no eases on hover,
  press, modal entry, or focus."* The only animations that exist are chrome-layer
  brand flourishes (e.g. `rainbow-draw` on first paint); product surfaces render
  instantly. Don't add transitions to buttons, panels, modals, or focus.
- **Don't put shadows on anything but buttons.** *"No shadows except on buttons.
  Cards, panels, modals, inputs — all flat. Hairline border does the work."*
  Only `--shadow-button`, `--shadow-button-hover`, `--shadow-button-press` are
  live. `--shadow-card` is kept as a neutralized legacy alias (`none`) so old
  call sites don't break — new code must not reach for it. Separation is
  `--color-border` (`#ede8e0`) hairlines, never elevation.
- **Don't use pure white or harsh black in the paper layer.** The page is
  `--color-background` `#fffdf7`; cards step UP to `--color-card` `#fff9f0`
  (warmer, not whiter); foreground is `--color-foreground` `#2d2a26`, never
  `#000`. (`--color-surface: #ffffff` exists for legacy chrome only — don't reach
  for it on new paper surfaces.)
- **Don't introduce new fonts, colors, button visuals, or a CSS framework.** The
  display face is Fraunces (variable, dialed warm), the reading face is
  Instrument Sans. Colors come from tokens; the rainbow comes from the `--logo-*`
  aliases. *"Display is dialed warm (Fraunces, SOFT 100, WONK 0). No quirky
  spurs, no slab terminals — if it reads brash, it is wrong."*
- **Don't hard-code hex values or pixel sizes that exist as tokens.** Use
  `--text-*`, `--space-*`, `--radius-*`, `--color-*`, `--logo-*`. The scale is
  closed (see below); a one-off size or color is a bug.
- **Don't ship emoji, exclamation points, marketing voice, or AI tells.** *"No
  emoji, no exclamation points, no marketing voice, no AI tells."* The copy
  carries the warmth.
- **Don't drift the rainbow-web mark.** The globe geometry is the data dictionary
  in `src/renderer/tokens/rainbow-web.json` — thick strokes, the multi-colored
  globe. A single edit there updates every surface; don't fork the SVG inline.

## Read first

- `src/renderer/design-tokens.css` — the product-layer token file, loaded after
  `styles.css`. Owns: the Fraunces/Instrument Sans stacks and
  `--font-display-settings` (`"SOFT" 100, "WONK" 0, "opsz" 144`); the `--logo-*`
  rainbow palette and the `--color-rose/peach/amber/mint/sky/indigo/violet`
  pastel aliases; the type scale (`--text-display-lg` 38 / `--text-display` 22 /
  `--text-essay` 17 / `--text-base` 15 / `--text-body` 14 / `--text-small` 13 /
  `--text-micro` 11); spacing (`--space-1` 4 … `--space-8` 48); radii
  (`--radius-pill` 999 / `--radius-card` 12 / `--radius-button` 10 /
  `--radius-chip` 9 / `--radius-icon` 8 / `--radius-logo-tile` 44); the
  button-only shadow tokens + `--focus-ring`; the motion note; the `--edge-*`
  rainbow-wedge tokens; and `--color-accent-press` `#4f46e5`.
- `src/renderer/styles.css` — the component canon (3000+ lines). The base
  `:root` block (`--color-background` `#fffdf7`, `--color-card` `#fff9f0`,
  `--color-border` `#ede8e0`, `--color-foreground` `#2d2a26`, `--color-accent`
  `#a5b4fc`, `--color-accent-strong` `#6366f1`, `--color-forest` `#2d5a3d`), the
  paper background, the rainbow `linear-gradient` usage (the welcome edge wedge,
  the sidebar phrase-border cycle, the pitch rows), and the `.pitch-script__*`
  component block.
- `src/renderer/tokens/rainbow-web.json` — the globe brand-mark data dictionary
  (viewBox, strokes, latitudes/longitudes with their `--logo-*` hues). Shared
  verbatim with the upstream UI repo.
- `src/renderer/tokens/README.md` — the style-dictionary index. Confirms the
  renderer reads each mark via `src/renderer/lib/<name>.js`, and that living
  inside `src/renderer/` means the files travel with both the Electron renderer
  and the Capacitor `webDir`.
- `src/renderer/design-system/` — the bundled design-system reference, a single
  `index.html`. Title `tinker — design system`. Loads Fraunces + Instrument Sans
  from Google Fonts, documents the marks, colors, type, spacing, shadows, and
  components, and carries the *"What this system never does"* house-rules block
  that the rest of the product cites.
- `src/renderer/index.html` — the Google Fonts loader for Fraunces + Instrument
  Sans, and where `styles.css` then `design-tokens.css` are loaded in order.

## What you're building, in one paragraph

A two-file token system plus a reference page. `design-tokens.css` is the
product-layer extension: it mirrors the design-system bundle and is loaded after
`styles.css` so it extends the production `:root` without disturbing it. It
defines the warm type pairing (Fraunces display, Instrument Sans reading), the
closed type / spacing / radii scales, the `--logo-*` rainbow palette and its
pastel aliases, the button-only shadow set and `--focus-ring`, and the `--edge-*`
rainbow-wedge tokens used by the welcome corner and the sidebar mirror.
`styles.css` holds the component styling against those tokens: a paper page at
`#fffdf7`, cards a half-step warmer at `#fff9f0`, hairline `#ede8e0` borders
doing all the separation, the CTA in `--color-accent-strong` `#6366f1` with
`#4f46e5` on press, and the rainbow used as a `linear-gradient` along the
welcome edge, the sidebar phrase-border cycle, and pitch rows. `tokens/`
carries the `rainbow-web.json` globe dictionary plus its `README.md`;
`design-system/` is the bundled `index.html` reference that renders the marks,
scales, and the never-do list. The whole system reads calm, warm, and still:
display dialed warm, no motion in the product layer, shadows only on buttons, no
pure white and no harsh black, the rainbow-web globe as the mark.

## Build sequence

1. **Establish the tokens (`src/renderer/design-tokens.css`).** Define the
   typography (`--font-display` Fraunces stack, `--font-sans` Instrument Sans
   stack, `--font-display-settings: "SOFT" 100, "WONK" 0, "opsz" 144`,
   `--font-mono`); the full pastel rainbow (`--color-rose/peach/amber/mint/sky/
   indigo/violet` with their `-light` companions) and the rainbow-web logo
   aliases (`--logo-pink` `#f9a8d4`, `--logo-orange` `#fdba74`, `--logo-yellow`
   `#fde68a`, `--logo-leaf` `#7bc47a`, `--logo-sky` `#7dd3fc`, `--logo-mint`
   `#6ee7b7`, `--logo-purple` `#c8b6e2`); the type scale, leading, tracking;
   the spacing scale (`--space-1`…`--space-8`); the radii; `--color-accent-press`
   `#4f46e5`; the `--color-selection` and semantic error tokens; and the
   `--edge-*` rainbow-wedge tokens. Load it after `styles.css` in
   `src/renderer/index.html` so it extends the production `:root`.
   **CHECKPOINT — stop and report.** Confirm `design-tokens.css` loads after
   `styles.css`, every `--logo-*` and `--text-*`/`--space-*`/`--radius-*` token
   resolves in the computed styles, and `--font-display-settings` is applied
   wherever Fraunces is used.

2. **Establish the shadow + focus + motion rules.** Define only
   `--shadow-button` / `--shadow-button-hover` / `--shadow-button-press` and
   `--focus-ring` (`0 0 0 4px rgba(99,102,241,0.18)`). Keep `--shadow-card` as a
   neutralized legacy alias (`none`). Add the motion comment block stating no
   `--motion-*` tokens exist. In `styles.css`, apply shadows to buttons only;
   give cards, panels, modals, inputs, and the spectrum/feed surfaces a
   `--color-border` hairline and no lift; use `--focus-ring` for focus, never an
   outline; and add zero transitions/animations to product surfaces (chrome-layer
   brand flourishes like `rainbow-draw` are the only exception, and stay out of
   the product layer).
   **CHECKPOINT — stop and report.** Confirm only buttons cast a shadow, every
   other surface is flat with a hairline, focus shows the halo not an outline,
   and no product-surface element carries a transition or animation.

3. **Style components against the tokens, and ship the brand + reference.** In
   `styles.css`: paper page `--color-background` `#fffdf7`; cards a warm step up
   to `--color-card` `#fff9f0`; CTA fill `--color-accent-strong` `#6366f1` with
   `--color-accent-press` `#4f46e5` on `:active`; the rainbow used as
   `linear-gradient` along the welcome edge wedge (`--edge-fill`), the sidebar
   phrase-border `--logo-*` cycle, and pitch rows; foreground `--color-foreground`
   `#2d2a26` (never `#000`). Keep `tokens/rainbow-web.json` as the single globe
   dictionary (read via `src/renderer/lib/<name>.js`) with its `README.md` index,
   and keep `src/renderer/design-system/index.html` as the bundled reference that
   renders the marks, the type/spacing/radii scales, and the *"What this system
   never does"* house-rules block. Any other prompt that needs a visual rule
   cites this page rather than restating it.
   **CHECKPOINT — stop and report.** Confirm the page reads warm (no pure white,
   no harsh black), the CTA uses the indigo accent with its press state, the
   rainbow gradient renders on the welcome edge and the sidebar phrase borders,
   and the design-system bundle and `rainbow-web.json` are in sync with the
   tokens.

## Constraints (non-negotiable)

- **Closed scales.** Type: 38 / 22 / 17 / 15 / 14 / 13 / 11 only. Spacing:
  4 / 6 / 8 / 12 / 16 / 24 / 32 / 48 only. Radii: 999 (pill) / 44 (logo-tile) /
  12 (card) / 10 (button) / 9 (chip) / 8 (icon) only. Reference via token, never
  a raw value.
- **Color via tokens.** Page `--color-background` `#fffdf7`, card `--color-card`
  `#fff9f0`, border `--color-border` `#ede8e0`, foreground `--color-foreground`
  `#2d2a26`, brand `--color-forest` `#2d5a3d`, CTA `--color-accent-strong`
  `#6366f1`, press `--color-accent-press` `#4f46e5`, rainbow via the `--logo-*`
  aliases. No hard-coded hex where a token exists.
- **Type.** Fraunces (`var(--font-display)`) for display with
  `var(--font-display-settings)` applied; Instrument Sans (`var(--font-sans)`)
  for reading. Dialed warm — SOFT 100, WONK 0. No new fonts.
- **Shadows: buttons only.** `--shadow-button` / `-hover` / `-press`. Everything
  else is flat with `--color-border` hairlines. `--shadow-card` is a neutralized
  legacy alias; don't use it.
- **Motion: none in the product layer.** No `--motion-*` tokens, no transitions,
  no animations, no eases on hover/press/modal/focus. State changes are instant.
- **No pure white, no harsh black** on paper surfaces. Page `#fffdf7`, cards step
  to `#fff9f0`, ink `#2d2a26`.
- **The rainbow-web mark is the identity.** Built from
  `tokens/rainbow-web.json`; a single dictionary edit updates every surface.
- **No emoji, no exclamation points, no marketing voice, no AI tells.**
- **Stays inside `src/renderer/`.** Tokens and the reference travel with both the
  Electron renderer and the Capacitor `webDir`; no new top-level directory, no
  bundler, no CSS framework.
