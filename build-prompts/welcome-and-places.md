# Build the tinker welcome surface and places (seeds)

> Version: v0.100
> Generated by the founder-package skill (product spec flow).
> Reconstructed from shipped code by the build-prompts audit (2026-05).

This is tinker's front door: the welcome/start surface where a founder picks a
place to write from, and the "places" system (seeds) that remembers those places,
groups them into a Claude-managed category taxonomy, and lists every essay
written under a tapped category. A seed is a place the founder reflects from — a
single string like `Cafe`, `Kitchen counter, 7am`, or a transaction merchant.
The welcome grid's four tiles (Cafe / Home / Work / Somewhere else) start a
writing session seeded with that place; the home list shows past seeds as cards
grouped by category; tapping a card opens that category's feed of essays. The
surface is already shipped across `src/renderer/seeds.js`,
`src/renderer/heatmap.js`, the `<section id="welcome">` / `<section id="category-feed">`
markup, and the welcome grid wiring in `renderer.js`. Read those before changing
anything.

> **Naming note — read first.** Internally this system is the **seeds** system,
> not "earths". The storage key is **`tinker.seeds.v1`** (with
> `tinker.seeds.hidden.v1` for tombstones); the public API is
> **`window.tinkerSeeds`**; the module is **`src/renderer/seeds.js`** (it was
> never renamed to `earths.js`). The word `earth` survives only as a field alias
> in `src/renderer/sidebar-tree.js`, which reads `w.earth || w.seed` and exposes
> `normalizeEarthKey` / `loadHiddenEarths` over the same `tinker.seeds.hidden.v1`
> key. There is **no `tinker.earths.v1` key anywhere** — do not introduce one.
> Use `tinker.seeds.v1` and `window.tinkerSeeds`.

## Anti-patterns — do not repeat

- **Don't ship a fixed category list.** The taxonomy is *Claude-managed and
  growing* — *"the categories are not a fixed list"* (`heatmap.js`). Each new
  seed is placed by the classifier into an existing top-level, a new sub-category
  under an existing top-level, or a brand-new top-level. Never hard-code the
  buckets.
- **Don't let the classifier author founder-facing prose.** It returns only
  structured placement JSON (`assignments` + `newCategories`) — category names
  (2–5 words, title case) and descriptions (exactly 4 words). It never writes the
  founder's essays and never paraphrases their writing.
- **Don't freeze a seed in Unsorted on failure.** A classifier failure must NOT
  persist an `UNSORTED` placement with the live fingerprint — that froze
  classification forever (the legacy bug the `tinker.taxonomy.unstuck_legacy.v1`
  purge cleans up). On failure, leave the seed in the PENDING bucket and back off
  (`CLASSIFY_RETRY_MS`), so a later render retries.
- **Don't reclassify unchanged writing.** Re-ask Claude only when the content
  fingerprint (`fingerprintContent`) shifts. Unchanged seeds keep their cached
  placement.
- **Don't make the welcome page a wall of identical rows.** Seed names like
  *"I want to be able to manage my landscaping"* are shortened to Slack-style
  channel labels (`channelName`) for display; the full text stays in the card's
  `title` attribute.
- **Don't reintroduce the preview-seed defaults.** The four old demo seeds
  (`Provecho`, `Industrious`, `Living room`, `Bedroom`) are purged on clients that
  received them; never re-seed them.
- **Don't design new chrome.** Inherit tinker's existing shell — the rainbow mark,
  the paper background, the tinker rainbow `PALETTE` for avatars. No motion.

## What you're building, in one paragraph

The welcome surface (`<section id="welcome">`) opens with the standing line
`Everyone is a founder.`, the sub `You just need a seed to start.`, the prompt
`Where are you right now?`, and a 2×2 grid of place tiles — **Cafe**, **Home**,
**Work**, **Somewhere else** — each a `<button data-location="…">`. Clicking Cafe,
Home, or Work calls `startSessionWith(label)`: it adds that place as a seed via
`window.tinkerSeeds.add(seed)` and opens a fresh writing session
(`window.tinkerNewSession({ seed })`) whose draft carries that place forward
(read downstream as the writing's `seed`, aliased `earth` in the sidebar).
"Somewhere else" reveals `#welcome-form` so the founder types their own place,
which submits the same way. The **seeds** module (`seeds.js`, `tinker.seeds.v1`)
remembers places — merged from explicit adds, past draft/essay seeds, and
transaction merchants — and exposes them via `window.tinkerSeeds.list()`. The
home list (`heatmap.js`) renders each seed as a card grouped under a category
the Claude classifier (`claude-haiku-4-5-20251001`, through
`api/claude/converse.js`) assigns into a **growing taxonomy**
(`tinker.taxonomy.v1`); cards display a Slack-style channel name, a rainbow
avatar from the shared `PALETTE`, and the title of the latest writing made there.
Tapping a card prefers the seed's **category feed** — `window.tinkerShowCategoryFeed`
opens `<section id="category-feed">`, which lists every published essay sharing
that leaf category and carries a status composer for quick posts — and falls back
to opening the latest essay, resuming the in-progress draft, or spinning up a
fresh session.

## Build sequence

1. **Build the welcome surface.** Render `<section id="welcome">` exactly as in
   `index.html`: the rainbow logo, `Everyone is a founder.`, `You just need a
   seed to start.`, `Where are you right now?`, and `#welcome-grid` with four
   `data-location` tiles labelled `Cafe`, `Home`, `Work`, `Somewhere else`. Add
   the hidden `#welcome-form` (`#welcome-input` placeholder `Where are you?`, a
   `Start →` submit). No motion; tinker chrome only.

2. **Wire the grid in `renderer.js`.** Map `LOCATION_LABELS = { cafe: "Cafe",
   home: "Home", work: "Work" }`. On a tile click: if `data-location="other"`,
   reveal `#welcome-form`, mark the tile `aria-pressed`, and focus the input; for
   the other three, call `startSessionWith(label)`, which calls
   `window.tinkerSeeds.add(seed)` then `window.tinkerNewSession({ seed })`. Wire
   the form submit to `startSessionWith(typedName)`. The chosen place becomes the
   draft's `seed`, carried into the writing flow.
   **CHECKPOINT — stop and report.** Click Cafe/Home/Work — confirm each opens a
   writing session seeded with that place (the writing flow's opening question
   moods to it). Click "Somewhere else" — confirm the input reveals, focuses, and
   submitting starts a session seeded with the typed place. Confirm the place is
   added to `tinker.seeds.v1`.

3. **Build the seeds store (`seeds.js`).** Storage `tinker.seeds.v1` +
   `tinker.seeds.hidden.v1`. Implement `listMerged()` to merge: explicit seeds,
   `seed` values on past drafts (`tinker.drafts.v1`) and essays
   (`tinker.essays.v1`) — pulling content snippets so the classifier can read what
   was written there — and transaction merchants from
   `window.tinkerTransactions.list()`. Each merged seed carries `usageCount`,
   `lastUsed`, `contentSnippets`, and `latestWriting`; tombstoned (removed) seeds
   are filtered out. Implement `addSeed` (untombstones on re-add), `removeSeed`
   (tombstones), the `openAddModal` add-seed dialog, `subscribe`, and the
   `migrateFromLocations()` + `purgeOldSeedDefaults()` one-time migrations. Expose
   `window.tinkerSeeds = { list, add, remove, subscribe, openAddModal }`. Re-read
   and re-notify on `tinker:hydrated` and on transaction changes.

4. **Build the home list + classifier (`heatmap.js`).** `render(mountEl)` reads
   `window.tinkerSeeds.list()` and buckets each seed: PENDING (no valid cached
   placement, or the content fingerprint shifted) vs. categorised (grouped by leaf
   category). Render PENDING first under a `Sorting…` header, then categorised
   sections (sub-categories nested under their parents) with breadcrumb headers
   and 4-word descriptions. After paint, fire `classifyUncategorized(pendingItems,
   state)`: build the existing-taxonomy text + per-seed snippet blocks, call
   `window.tinker.callClaude({ system, messages, model: "claude-haiku-4-5-20251001",
   maxTokens: 600 })`, parse the `{ assignments, newCategories }` JSON, register
   new categories, auto-create referenced-but-undeclared path segments, validate
   parents, and place each seed into one or more `paths` keyed by content
   fingerprint. On failure, do NOT persist a placement — back off and retry. Each
   card (`renderCard`) shows a `PALETTE` avatar, the `channelName`, and the latest
   writing title.
   **CHECKPOINT — stop and report.** With several seeds present, confirm: the home
   list renders cards grouped under Claude-assigned categories; a new seed shows
   under `Sorting…` then lands in a category; unchanged seeds aren't reclassified;
   a forced classifier failure leaves the seed PENDING (not frozen in Unsorted)
   and retries on a later render.

5. **Tap routing + the category feed.** `openSeed(seed)` prefers the seed's
   category feed: resolve its leaf category, and if it has essays call
   `window.tinkerShowCategoryFeed(leafKey, seedName)`. Otherwise fall back to
   `window.tinkerOpenEssay` (latest essay), `window.tinkerResumeDraft`
   (in-progress draft), or `window.tinkerNewSession({ seed })`. In `renderer.js`,
   `showCategoryFeed` opens `<section id="category-feed">`: set
   `#category-feed-title` to the category name, build the list from
   `window.tinkerHeatmap.getCategoryFeed(categoryKey)` (every non-archived essay
   whose seed's path ends in that leaf, newest first), render `#category-feed-list`
   cards, show `#category-feed-empty` (`No essays here yet.`) when empty, and wire
   the `#status-composer` for quick posts attached to the originating seed.
   `getCategoryKeyForSeed` lets the publish flow land a freshly published essay on
   its category feed.
   **CHECKPOINT — stop and report.** Tap a seed card that has essays — confirm the
   category feed lists every essay sharing that leaf category, newest first, with
   the title set to the category name. Tap a seed with no essays — confirm it
   resumes the draft or starts a fresh session. Confirm the status composer posts
   attach to the tapped seed.

## Constraints (non-negotiable)

- **Storage keys are exact.** Seeds: `tinker.seeds.v1` (+ `tinker.seeds.hidden.v1`).
  Taxonomy: `tinker.taxonomy.v1`. Drafts: `tinker.drafts.v1`. Essays:
  `tinker.essays.v1`. Pitches: `tinker.pitches.v1`. There is **no
  `tinker.earths.v1`** — never create one. The `earth` field is only an alias for
  `seed` read in `sidebar-tree.js`.
- **The taxonomy is generative, not fixed.** Categories grow via the classifier;
  never hard-code the buckets. Names 2–5 words title case; descriptions exactly 4
  words. Max nesting depth 2.
- **The classifier never authors founder-facing prose.** It returns placement
  JSON only — never essays, never paraphrase.
- **One model per call site.** The seed/taxonomy classifier uses
  `claude-haiku-4-5-20251001` (matching `api/classify/index.js`) through
  `api/claude/converse.js`; the writing engine a tile opens into uses
  `claude-opus-4-7`; the search edge (`api/search.js`) uses `claude-haiku-4-5`.
  **There is no `claude-sonnet-4-6` in this codebase — never write it.**
- **Failures back off; they don't freeze.** Never persist an `UNSORTED` placement
  with a live fingerprint on classifier failure. Leave PENDING, back off, retry.
- **Reclassify only on content change.** Gate re-classification on the
  fingerprint; unchanged seeds keep their placement.
- **Tinker chrome, no motion.** Inherit the existing shell, the rainbow mark, and
  the rainbow `PALETTE`. State changes are instant.

## Done when

- The welcome surface renders the four place tiles (Cafe / Home / Work /
  Somewhere else); Cafe/Home/Work start a writing session seeded with that place,
  and "Somewhere else" reveals an input that does the same with a typed place.
- Starting a session adds the place to `tinker.seeds.v1` and carries it into the
  draft's `seed` field (read as `earth` alias in the sidebar).
- The home list renders each seed as a card grouped under a Claude-assigned
  category in the growing `tinker.taxonomy.v1` taxonomy; new seeds sort in via the
  `claude-haiku-4-5-20251001` classifier; classifier failures stay PENDING and
  retry, never frozen.
- Tapping a seed card opens that leaf category's feed (`<section id="category-feed">`,
  every shared-category essay newest-first) when essays exist, and falls back to
  the latest essay / in-progress draft / a fresh session otherwise.
- No `tinker.earths.v1` key and no `claude-sonnet-4-6` anywhere.
